# RanobeLib to EPUB Downloader

Скрипт на Python для автоматического скачивания глав ранобэ с сайта [RanobeLib](https://ranobelib.me/) и их сборки в готовую электронную книгу формата `.epub`. Скрипт использует Playwright для обхода защиты, автоматического скроллинга страниц и обработки всплывающих окон (18+).

## Требования

Для работы скрипта потребуется Python 3.7 или выше.
Установите необходимые библиотеки:

```bash
pip install playwright ebooklib

```

После установки Playwright необходимо загрузить браузер Chromium:

```bash
playwright install chromium

```

## Настройка

Перед запуском откройте скрипт в любом текстовом редакторе и измените блок **НАСТРОЙКИ** под нужную вам книгу:

```python
# ================= НАСТРОЙКИ =================
SLUG = "94231--rezero-kara-hajimeru-isekai-seikatsu-outo-no-ichinichi-hen" # Часть URL книги
NOVEL_NAME = "ReZero" # Базовое название для файла
EPUB_AUTHOR = "Tappei Nagatsuki" # Автор книги

# Фильтрация
START_VOL = 24  # С какого тома начать
END_VOL = 28    # Каким томом закончить
START_CHAPTER = None  # None — качать с первой главы. Укажите число, если нужно начать с середины (например, 69)

DELAY_MIN = 2.0 # Минимальная задержка между скачиванием (в секундах)
DELAY_MAX = 4.0 # Максимальная задержка
# ============================================

```

**Как найти SLUG:**
Зайдите на страницу книги на RanobeLib. В адресной строке вы увидите URL вида: `[https://ranobelib.me/ru/book/94231--rezero](https://ranobelib.me/ru/book/94231--rezero)...`. Все, что идет после `book/` и до знака `?` — это и есть SLUG.

## Запуск

Сохраните скрипт в файл, например `main.py`, и запустите его в терминале:

```bash
python main.py

```

Откроется окно браузера. Скрипт автоматически проскроллит оглавление, найдет нужные главы согласно фильтрам, скроет предупреждение об ограничении 18+ и поочередно скачает текст. По завершении в папке со скриптом появится готовый файл `.epub`.
